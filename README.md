# 🚗 Calculadora de Viagem e Comparativo de Combustível

Um script em Python desenvolvido para calcular o custo total de uma viagem rodoviária (incluindo combustível e pedágios) e comparar financeiramente o uso entre **Gasolina** e **Etanol** com base no consumo específico do seu veículo e na relação de preços.

## 🚀 Funcionalidades

* **Cálculo de Consumo e Custos:** Calcula a quantidade de litros necessários e o custo em dinheiro para a distância informada.
* **Inclusão de Pedágios:** Soma automática dos gastos com pedágios ao custo final da viagem.
* **Comparativo Inteligente:** Analisa o rendimento real informado pelo usuário e aponta qual combustível é mais vantajoso financeiramente.
* **Relação de Preços (%):** Exibe a porcentagem do preço do Etanol em relação à Gasolina para fácil referência.
* **Tratamento de Erros:** Valida entradas inválidas e impede valores negativos ou zerados.

## 🛠️ Tecnologias Utilizadas

* **Python 3** (Módulos nativos e lógica estruturada)
